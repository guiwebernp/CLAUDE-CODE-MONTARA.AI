🚀 PRÓXIMOS PASSOS (Para você)

[1] Criar repositório no GitHub
    → github.com/new → nome: rdo-site

[2] Fazer push (PowerShell)
    → git push -u origin main

[3] Conectar Vercel
    → vercel.com → Import do repositório

[4] Escolher provedor SMTP
    → Abra SMTP_SETUP.md e escolha (Gmail recomendado)

[5] Testar localmente (importante!)
    → npm install && npm run dev

[6] Adicionar variáveis em Vercel Dashboard
    → Settings → Environment Variables

[7] Testar em produção
    → Preencha o formulário e confirme o e-mail

⏳ Tempo estimado: 30-45 minutos
