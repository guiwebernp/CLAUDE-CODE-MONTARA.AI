PASSO 5: Adicionar Variáveis no Vercel Dashboard
────────────────────────────────────────────────────────────────────────────────
1. vercel.com/dashboard → seu projeto
2. "Settings" → "Environment Variables"
3. Adicione as 7 variáveis (veja SMTP_SETUP.md):
   - CONTACT_EMAIL
   - SMTP_HOST
   - SMTP_PORT
   - SMTP_SECURE
   - SMTP_USER
   - SMTP_PASS
   - SMTP_FROM

4. Clique "Save"
5. Vercel faz deploy automático
