║  SEGURANÇA & BEST PRACTICES                                  ║
╚═══════════════════════════════════════════════════════════════╝

✅ XSS Prevention
   - HTML escape no backend (api/contact.js)
   - Previne injeção de JavaScript

✅ Input Validation
   - Frontend: validação visual
   - Backend: validação de integridade
   - Ambas são necessárias

✅ Secrets Management
   - .env em .gitignore
   - Variáveis sensíveis NÃO são commitadas
   - Apenas em Vercel Dashboard

✅ HTTPS
   - Automático na Vercel
   - Toda comunicação é criptografada

✅ Rate Limiting (Futuro)
   - Pode ser adicionado se tiver spam
   - Vercel oferece suporte

╔═══════════════════════════════════════════════════════════════╗
║  WORKFLOW: Como Fazer Mudanças Depois                        ║
╚═══════════════════════════════════════════════════════════════╝

Depois de tudo deployado, para fazer mudanças:

1. Edite seu arquivo (ex: index.html)

2. Commit local
   git add .
   git commit -m "Descrição da mudança"

3. Push para GitHub
   git push origin main

4. Vercel detecta automaticamente
   → Começa deploy
   → ~1-2 minutos depois está no ar
   → Novo código em produção

Exemplo: Receber foto nova do portfólio
   • Salve em assets/portfolio/nova-foto.png
   • Atualize <img src> em index.html
   • Commit: git commit -m "Add nova foto portfólio"
   • Push: git push origin main
   • Pronto! Vercel faz deploy

║  RESUMO: 3 Partes Principais                                 ║
╚═══════════════════════════════════════════════════════════════╝

   └─ Entrega em CONTACT_EMAIL

Tudo rooda automaticamente. Vercel cuida da orquestração.
