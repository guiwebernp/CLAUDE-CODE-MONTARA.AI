# Clínica Reab — Site Moderno

> Projeto iniciado em 20 de julho de 2026. Redesign completo com design moderno e responsivo.

## Sobre

Criar um site mais moderno para Clínica Reab, melhorando a presença digital e permitindo agendamento online de consultas.

## Tipo

Cliente novo — clínica de fisioterapia em Florianópolis.

## Entregas previstas

- Site responsivo (desktop, tablet, mobile)
- Landing page com call-to-action para agendamento
- Design moderno e profissional

## Onde salvar o que

- Briefing e contexto: nessa pasta na raiz (`briefing.md`)
- Site: pasta `site/` (HTML, CSS, JS vanilla)
- Assets: `site/assets/` (imagens, ícones, etc)

## Contexto que herda da raiz

Esse projeto herda:
- Ferramentas: HTML/CSS/JS vanilla (sem frameworks)
- Deploy: Vercel
- Tom de voz: direto, amigável, contextual
- Identidade visual: cores e tipografia da WNP (antes Montara.AI) como base (customizar conforme marca do cliente)

## Stack

- **HTML:** Semântico, acessível, meta tags SEO
- **CSS:** Grid + Flexbox, mobile-first, CSS Variables para cores
- **JS:** Vanilla ES6+, sem dependências externas
- **Deploy:** Vercel (branch `main`)

## Específico desse projeto

- Foco em **conversão**: botões de agendamento/contato destacados
- Seção de **especialidades** ou **tratamentos** oferecidos
- Possível integração com agendamento online (a definir)
